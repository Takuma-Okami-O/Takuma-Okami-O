🚀 Proyecto destacado: Catálogo App

Construí esto de punta a punta: arquitectura, base de datos, API, app móvil y la página pública del catálogo.

📱 App del vendedor: Catalogo-App-Vendedor — React Native + Expo, TypeScript

Algunos retos técnicos que resolví ahí (con más detalle en cada README): manejo de cold-starts de infraestructura gratuita con recuperación de UX, multi-tenancy real con aislamiento de datos por caso de uso, autenticación JWT con renovación transparente de sesión, y un agente de ventas con IA integrado al catálogo.
